How it works

Five-module automated pipeline

Each module writes a structured output that feeds the next. Resume from any step using intermediate files.

Module 1
🌐

GEO Fetcher

Downloads scRNA-seq data from GEO, classifies tumour / normal samples, applies QC filters.

GEOparse · Scrublet
Module 2
🔬

Cell Annotation

Consensus cell-type annotation using 8 methods. Majority-vote prediction per cell.

PopV
Module 3
🧬

Malignant ID

Identifies malignant epithelial cells; performs surfaceome DE analysis filtered by CSPA.

scMalignantFinder · SCEVAN
Module 4a
🎯

Single Gene

Ranks candidate surface genes by tumour efficacy and off-tumour safety scores.

HPA reference
Module 4b
⚡

Two-Gene GA

Genetic algorithm searches AND / OR / NAND two-gene combinations for optimal targets.

DEAP genetic algorithm
Module 4b

Two-gene combination scoring

A genetic algorithm (DEAP) evaluates two-gene pairs across three logic gate types to maximise tumour coverage while minimising off-target risk.

A & B

AND Gate

CAR-T activates only when both genes are expressed on the same cell. Delivers the safest selectivity profile against healthy tissue.

Best safety
A | B

OR Gate

CAR-T activates when either gene is expressed. Maximises tumour cell coverage at the cost of slightly broader targeting.

Best coverage
A &! B

NAND Gate

CAR-T activates when gene A is expressed and gene B is absent. Exploits loss-of-expression patterns unique to tumour cells.

Exploits antigen loss
Features

Everything in one pipeline

SCART automates every step from raw data retrieval to ranked CAR-T target candidates.

📥

GEO Integration

Fetch any scRNA-seq dataset directly from NCBI GEO with automatic tumour/normal sample classification.

🗳️

Consensus Annotation

PopV runs 8 independent cell-type classification methods and reports a majority-vote prediction per cell.

🔍

Dual Malignancy Calling

Intersection of scMalignantFinder and SCEVAN provides high-confidence malignant cell identification.

🛡️

Safety Scoring

Off-tumour safety evaluated against 36 healthy tissue types from the Human Protein Atlas.

🧪

Surfaceome Filtering

DE candidates are automatically filtered against the Cell Surface Protein Atlas (3,568 genes).

⚙️

HPC Ready

Full SLURM / SBATCH support with per-module job scripts and dependency chaining guidance.

Built-in Surfaceome Reference

Four curated databases

All reference databases are either bundled or auto-downloaded at runtime. No manual setup required.
