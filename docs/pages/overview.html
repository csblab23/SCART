What is SCART?

SCART (Single-Cell Automated CAR-T target discovery) is an end-to-end computational pipeline for identifying tumour-specific surface protein targets for CAR-T cell therapy from single-cell RNA-seq data.

CAR-T therapy requires surface antigens that are highly expressed on tumour cells and absent (or minimally expressed) on healthy tissues. SCART automates this discovery by integrating GEO data retrieval OR manual h5ad by user, cell-type annotation, malignant cell identification, surfaceome differential expression, and logic-gate one and two gene combination scoring for CAR-T therapy targets into a single cohesive pipeline.

Pipeline Architecture

The pipeline consists of five sequential modules. Each module writes an output h5ad or CSV that serves as input to the next. All intermediate outputs are saved so you can resume from any step.

ModuleInputOutputKey tool
1 — GEO FetcherGEO accession ID / h5ad*_tumor.h5adGEOparse, Scrublet
2 — Cell AnnotationModule 1 outputfinal_popv_annotated.h5adPopV

Module 1 — GEO Fetcher

Downloads and parses scRNA-seq datasets from GEO, classifies samples as tumour / normal / unspecified, applies QC filters, and writes a tumour h5ad file for downstream analysis.

Basic usage

python
from SCART.geo_fetcher import SampleAnnotator

annotator = SampleAnnotator(
    "GSE131907",
    cancer_type="lung_cancer",
    min_genes=200,
    max_mt=40
)
normal, tumor, unspecified, info, path, ct, results = annotator.run()

Parameters

ParameterTypeDefaultDescription
*inputsstr—One or more GEO accession IDs (e.g. "GSE131907") or paths to .h5ad files
cancer_typestrrequiredCancer type label. Tabula Sapiens key for auto reference recommendation, or free-text string.
min_genesint or NoneNoneMinimum genes per cell for QC. None = QC skipped
max_mtfloat or NoneNoneMaximum mitochondrial % per cell
manual_annotation_colstr or NoneNoneobs column name with your own cell-type labels. When set, Module 2 (PopV) is skipped.
exclude_gsm_idslist or NoneNoneList of GSM IDs to exclude (e.g. engineered CAR-T products)
💡
To see all valid Tabula Sapiens cancer type keys: from SCART.geo_fetcher import VALID_CANCER_TYPES; print(VALID_CANCER_TYPES)

Sample classification logic

Each GSM is classified in strict priority order (first match wins): normal (keywords: normal, healthy, control, adjacent normal, non-tumor…) → tumor (keywords: carcinoma, malignant, aml, cml, leukemia, lymphoma, myeloma, glioblastoma, melanoma, sarcoma…) → unspecified.

Module 2 — Cell-Type Annotation (PopV)

Annotates cell types using PopV, a consensus framework running 8 methods and reporting a majority-vote prediction per cell. Can be skipped entirely when manual_annotation_col was provided in Module 1.

Basic usage

python
from SCART import popv_annotation

adata = popv_annotation.auto_run_popv(
    input_type     = "raw",
    nsamples       = 300,
    user_reference = "/path/to/Lung_TSP1_30_version2d_10X_smartseq_scvi.h5ad"
)

Parameters

ParameterTypeDefaultDescription
input_typestr"raw""raw" for raw counts; "log1p" for pre-normalised data (runs CellTypist only)
nsamplesint300Cells sampled per cell-type label during reference subsampling
output_dirstr"popv_results"Directory where final_popv_annotated.h5ad is saved
user_referencestr or NoneNonePath to Tabula Sapiens tissue h5ad. If None, auto-downloaded from Figshare
drop_reference_columnsboolTrueRemove Tabula Sapiens metadata columns from output
ℹ️
Tabula Sapiens tissue references are available at figshare.com/27921984. Module 1 prints the recommended file name for your cancer type.

Module 3 — Malignant Cell Identification

Identifies malignant epithelial cells using scMalignantFinder and SCEVAN. Performs surfaceome DE analysis (Wilcoxon rank-sum, malignant vs non-malignant) filtered against the CSPA database. Outputs a binarised tumour expression matrix for Module 4.

Epithelial cells are selected by substring-matching "epithelial cell" (case-insensitive) in the popv_majority_vote_prediction column.

Basic usage

python
from SCART import preprocessing

adata_preprocessed = preprocessing.run_preprocessing_pipeline(
    reference_h5ad     = "/path/to/tissue_reference.h5ad",
    log2fc_threshold   = 2.0,
    pval_adj_threshold = 0.05,
    malignant_strategy = "intersection",
)

Malignant strategy options

StrategyDescription
"intersection"Recommended. Cell must be called malignant by both scMalignantFinder AND SCEVAN. Most stringent, highest confidence.
"scMalignant"Use only scMalignantFinder. Does not require SCEVAN or a reference h5ad.
"scevan"Use only SCEVAN CNV analysis. Requires reference_h5ad.

Key parameters

ParameterDefaultDescription
log2fc_threshold1.0DEG log2 fold-change cutoff
pval_adj_threshold0.05BH-adjusted p-value cutoff
reference_h5adNoneNormal tissue reference for SCEVAN. SCEVAN skipped if None.
scevan_ref_max_cells500Max normal reference cells subsampled for SCEVAN
scevan_batch_size3000Query cells per SCEVAN batch
scevan_par_cores1CPU cores for parallel SCEVAN batches

Module 4a — Single-Gene Scoring

Scores every surfaceome-DE gene for efficacy (tumour coverage) and safety (healthy tissue sparing). Outputs a ranked CSV of all candidate genes.

python
from SCART.gene_combination_predictor import one_gene_combination

df = one_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
)

df_filtered = df[df["Safety"] >= 0.9].sort_values("Efficacy", ascending=False)
print(df_filtered.head(10))
ParameterDefaultDescription
safety_threshold0.9Minimum fraction of healthy cells that must NOT express the gene
hpa_pathNoneHealthy reference (h5ad or tsv). Auto-downloaded if None.
tumor_pathNoneModule 3 output. Auto-detected if None.

Module 4b — Two-Gene Logic-Gate Scoring

Uses a genetic algorithm (DEAP) to search optimal two-gene combinations with AND, OR, and NAND logic gates. Runs multiple independent random-seed runs for robust discovery.

python
from SCART.gene_combination_predictor import two_gene_combination

df_hof, df_all = two_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
    pop_size         = 1000,
    Gmax             = 100,
    patience         = 50,
    n_cpus           = 8,
    n_runs           = 10,
)

Logic gates evaluated

GateSymbolMeaning
ANDA & BBoth genes expressed on the same cell. Best safety profile.
ORA | BEither gene triggers activation. Best tumour coverage.
NANDA &! BGene A expressed AND gene B absent. Exploits loss-of-expression patterns.

Hardware recommendations

python
# Laptop (quick test)
two_gene_combination.run(pop_size=200, Gmax=20, patience=10, n_cpus=4, n_runs=2)

# Standard workstation
two_gene_combination.run(pop_size=1000, Gmax=100, patience=50, n_cpus=8, n_runs=10)

# HPC node
two_gene_combination.run(pop_size=2000, Gmax=200, patience=100, n_cpus=40, n_runs=10)

Manual Annotation — Skip PopV

If you already have cell-type annotations (from Seurat, Scanpy, CellTypist, etc.), provide your annotation column in Module 1 to skip PopV entirely.

python
annotator = SampleAnnotator(
    "my_data.h5ad",
    cancer_type="ovary_cancer",
    manual_annotation_col="cell_type",  # your obs column
    min_genes=200,
    max_mt=40,
)
# Then skip Module 2 — go directly to Module 3
⚠️
Label requirement: Epithelial cell labels must contain the substring "epithelial cell" (case-insensitive). Labels like "epithelial" or "Epithelial_cells" will NOT be recognised. Examples that work: "glandular epithelial cell", "lung epithelial cell", "ovarian surface epithelial cell".
