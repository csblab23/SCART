Requirements

SCART requires Python 3.10 and R for the SCEVAN module. The recommended installation uses conda for environment management.

RequirementVersionNotes
Python3.10Other versions not tested
R≥ 4.1Required for SCEVAN (Module 3)
conda / mambaanyRecommended for environment management
RAM≥ 16 GB32 GB+ recommended for large datasets
Disk≥ 20 GBFor GEO downloads + reference files

Step 1 — Create Conda Environment

Create a dedicated conda environment with Python 3.10. Using a dedicated environment avoids dependency conflicts.

bash
# Create and activate the environment
conda create -n scart_env python=3.10 -y
conda activate scart_env

Step 2 — Install SCART (Python)

Installation steps differ slightly by operating system. Pick the tab that matches your platform.

On Windows, SCART's interactive installer handles all the tricky pip version-pinning for you. Just install the package and run the setup wizard.

Step 2a — Install SCART

bash
# Install from GitHub
pip install git+https://github.com/csblab23/SCART.git

Step 2b — Run the interactive setup

This handles all required pip fixes automatically, then prints the R / SCEVAN steps you'll need next.

bash
python -m SCART.install
# → choose [1] Linux
# → review the checklist, press y to confirm
# → after it finishes, follow the printed R + SCEVAN steps
⚠️
If python -m SCART.install doesn't work for the R dependencies — install them manually using the steps in Step 3 — R Dependencies below, then continue from there.

On Linux, a few Python packages need to be pre-pinned to specific versions before installing SCART itself, and annoy needs to be installed via conda and manually registered with pip.

Step 2a — Pre-install Python dependencies

bash
pip install "numpy>=1.24,<2.0"
pip install "scipy==1.12.0"
pip install "orbax-checkpoint<0.5" "flax<0.8"
pip install scvi-tools==1.1.6.post2
pip install "jax[cpu]==0.4.23" "jaxlib==0.4.23" "optax==0.1.7" "flax==0.7.5" "orbax-checkpoint<0.5" "numpyro<=0.13.2" "numpy>=1.24,<2.0" "scipy==1.12.0" --force-reinstall

Step 2b — Install annoy (no C++ compiler needed)

bash
conda install -c conda-forge python-annoy -y

python -c "
import site, os
sp = site.getsitepackages()[0]
di = os.path.join(sp, 'annoy-1.17.3.dist-info')
os.makedirs(di, exist_ok=True)
open(os.path.join(di, 'METADATA'), 'w').write('Metadata-Version: 2.1\nName: annoy\nVersion: 1.17.3\n')
open(os.path.join(di, 'RECORD'), 'w').write('')
open(os.path.join(di, 'INSTALLER'), 'w').write('conda\n')
print('annoy registered with pip successfully')
"

python -c "import annoy; print('annoy OK')"

Step 2c — Install SCART

bash
pip install git+https://github.com/csblab23/SCART.git

Step 2d — Torch version fix

bash
pip uninstall torch -y
pip install torch==2.2.2 --index-url https://download.pytorch.org/whl/cpu

Step 2e — Run the interactive setup

bash
python -m SCART.install
# → choose [2] Windows, press y — fully automated

Step 2f — Verify

bash
python -c "import SCART; from SCART.geo_fetcher import SampleAnnotator; print('All imports OK')"
Rscript -e "library(SCEVAN); cat('SCEVAN OK\n')"
⚠️
If python -m SCART.install doesn't work for the R dependencies — install them manually using the steps in Step 3 — R Dependencies below, then continue from there.

Step 3 (Optional) — Install R and SCEVAN Dependencies (Manual)

The interactive installer (python -m SCART.install) handles this automatically for most setups. Use these manual steps only if the installer fails, or if you prefer to install R dependencies yourself. Run all commands inside your activated scart_env conda environment.

3a. Install R base and system libraries via conda

bash
conda install -c conda-forge -c bioconda \
  r-base r-devtools r-remotes r-ggplot2 r-data.table \
  r-igraph r-gdtools r-ragg r-dplyr \
  cairo freetype fontconfig harfbuzz fribidi \
  libpng libtiff libjpeg-turbo libwebp \
  --override-channels -c conda-forge -c bioconda -c defaults \
  -y

3b. Install Bioconductor and R packages

bash
conda config --set channel_priority flexible
conda install -c conda-forge -c bioconda \
  bioconductor-scran bioconductor-fgsea \
  bioconductor-ggtree \
  r-paralleldist r-pheatmap r-forcats \
  r-cluster r-rtsne r-ape r-tidytree r-ggrepel \
  -y
⚠️
Windows only — use ^ instead of \ for line continuation:
bash
conda config --set channel_priority flexible
conda install -c conda-forge -c bioconda ^
  bioconductor-scran bioconductor-fgsea ^
  bioconductor-ggtree ^
  r-paralleldist r-pheatmap r-forcats ^
  r-cluster r-rtsne r-ape r-tidytree r-ggrepel ^
  -y

3c. Install SCEVAN from R

Open an R console inside the activated environment and run:

R
library(devtools)
install_github("miccec/yaGST")
install_github("AntonioDeFalco/SCEVAN")

# Verify installation
library(SCEVAN)
# Should load without error
💡
If devtools doesn't install or load correctly, try the lighter-weight remotes package instead — it provides the same install_github() function without devtools' heavier dependency footprint:
R
install.packages("remotes")
remotes::install_github("miccec/yaGST")
remotes::install_github("AntonioDeFalco/SCEVAN")

# Verify installation
library(SCEVAN)
# Should load without error

Step 4 — Jupyter Notebook Setup (optional)

Register the scart_env environment as a Jupyter kernel so you can run SCART notebooks interactively.

bash
pip install notebook ipykernel
python -m ipykernel install --user \
  --name=scart_env \
  --display-name "Python (scart_env)"
jupyter notebook

Step 5 — Verify Installation

Confirm SCART is installed and all imports work:

python
import SCART
    

# Test module imports
from SCART.geo_fetcher import SampleAnnotator
from SCART import popv_annotation
from SCART import preprocessing
from SCART.gene_combination_predictor import one_gene_combination
from SCART.gene_combination_predictor import two_gene_combination

# List all valid cancer type keys
from SCART.geo_fetcher import VALID_CANCER_TYPES
print(VALID_CANCER_TYPES)
✅
If all imports succeed without errors, you are ready to proceed to the Tutorial.

HPC / Cluster Notes

When running SCART on an HPC cluster (SLURM, PBS, etc.), install the conda environment in your home or project directory and load the appropriate modules before activating.

Running Python Scripts on the Cluster

New to running Python scripts from the command line? The Real Python guide — How to Run Your Python Scripts and Code covers all the essentials: using the python command, running modules with -m, and working interactively with the REPL. The most common pattern on a cluster is:

bash
# Basic usage — run a Python script from the command line
python my_script.py

# Redirect output to a file for later review
python my_script.py > output.txt

Submitting Jobs with SLURM

For large GEO downloads or compute-intensive modules, submit your work as a SLURM batch job rather than running it interactively. The JHU ARCH tutorial — How to Create a Slurm Script walks through all the key directives. A minimal script for running a SCART module looks like this:

bash
#!/bin/bash
#SBATCH --job-name=scart_job          # Job name
#SBATCH --output=output.txt           # Standard output file
#SBATCH --error=error.txt             # Standard error file
#SBATCH --partition=partition_name    # Partition or queue name
#SBATCH --nodes=1                     # Number of nodes
#SBATCH --ntasks-per-node=1           # Number of tasks per node
#SBATCH --cpus-per-task=4             # CPU cores per task
#SBATCH --time=4:00:00                # Maximum runtime (HH:MM:SS)
#SBATCH --mail-type=END               # Email on job completion
#SBATCH --mail-user=your@email.com    # Your email address

module load conda/latest
conda activate scart_env

python my_scart_script.py

Save the script (e.g. run_scart.slurm) and submit it with:

bash
sbatch run_scart.slurm

Python/Jupyter Notebook

The simplest way to explore SCART interactively is in a Jupyter notebook. You can run the entire pipeline in a single cell, or split each module into its own cell to inspect intermediate outputs as you go — both approaches work equally well.

💡
Make sure you have completed Step 4 (Jupyter Setup) and selected the Python (scart_env) kernel before running the cells below.

Option A — Run the full pipeline in one cell

Paste all modules into a single cell and execute at once. Useful for automated runs or re-running a saved notebook end-to-end. [This is a example dataset]

python
# ── Full SCART pipeline — single cell ──────────────────────────────────────

import SCART
from SCART.geo_fetcher import SampleAnnotator

annotator = SampleAnnotator("GSE158937", cancer_type="ovary_cancer", min_genes=200, max_mt=40)
normal, tumor, unspecified, annotation_info, query_h5ad, cancer_type, results = annotator.run()

from SCART import popv_annotation
adata = popv_annotation.auto_run_popv(
    nsamples=300,
    user_reference="/path/to/Ovary_TSP1_30_version2d_10X_smartseq_scvi_Nov262024.h5ad",
)

from SCART import preprocessing
adata_preprocessed = preprocessing.run_preprocessing_pipeline(
    adata              = None,
    log2fc_threshold   = 2.0,
    pval_adj_threshold = 0.05,
    reference_h5ad     = "/path/to/Ovary_TSP1_30_version2d_10X_smartseq_scvi_Nov262024.h5ad",
    malignant_strategy = "intersection",
    scevan_ref_max_cells = 100,
    scevan_sample_name   = "SCEVAN_run",
    scevan_organism      = "human",
    scevan_par_cores     = 1,
    scevan_subclones     = False,
    scevan_batch_size    = 3000,
)

from SCART.gene_combination_predictor import one_gene_combination
df = one_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
)

from SCART.gene_combination_predictor import two_gene_combination
df_hof, df_all = two_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
    pop_size         = 1000,
    Gmax             = 100,
    patience         = 50,
    n_cpus           = 8,
    n_runs           = 10,
)
