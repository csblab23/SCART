Before You Begin — Data Requirements

SCART is designed to be straightforward to use, even if you are new to computational tools. Before running any code, please read these three important rules. They will save you time and prevent the most common mistakes.

⚠️
Rule 1 — Always supply RAW (unnormalised) count data SCART expects raw integer count matrices — the unprocessed output from Cell Ranger or equivalent. Do not supply log-normalised, scaled, or batch-corrected data. Both GEO downloads and any h5ad files you provide must contain raw counts. SCART handles all normalisation internally.
⚠️
Rule 2 — One cancer type per analysis Each SCART run must focus on a single cancer type. Do not mix, for example, lung cancer samples with ovarian cancer samples in the same run. If you have data from multiple cancer types, run SCART separately for each.
⚠️
Rule 3 — Make sure your conda environment is active Every command and script on this page assumes you have activated your scart_env conda environment. If you have not set it up yet, please complete the Installation guide first.

Reference Files — Where to Download

SCART uses two types of external reference files. You need to download these once and store them somewhere accessible on your computer or cluster.

🧬
Tabula Sapiens tissue references (for Modules 2 & 3)

These are tissue-specific healthy-cell references used for cell-type annotation (PopV) and malignant cell identification (SCEVAN). Download the file that matches your cancer type from the table below.
→ Download from Figshare: doi.org/10.6084/m9.figshare.27921984

🛡️
Human Protein Atlas (HPA) healthy-tissue reference (for Module 4)

This file is used by Modules 4a and 4b to assess safety — i.e., whether a candidate target gene is expressed in healthy tissues. Download HPA_updated.h5ad from the SCART GitHub repository.
→ Download from HPA: https://www.proteinatlas.org/

Scenario 1 — Using GEO Accession ID(s)

SCART downloads the data directly from NCBI GEO. You only need the GEO ID(s) and your reference files. This is the most common starting point.

What you need before starting

  • A GEO accession ID (format: GSExxxxxx). Find these on ncbi.nlm.nih.gov/geo.
  • The Tabula Sapiens reference file for your cancer type (download from Figshare — see table above).
  • The HPA reference file HPA_updated.h5ad (download from HPA).
  • At least 20 GB free disk space and a stable internet connection for the download.
Variant A — Single GEO dataset (most common)

This example uses ovarian cancer dataset GSE158937. Replace the GEO ID, cancer_type, and file paths with your own values.

python
import SCART
from SCART.geo_fetcher import SampleAnnotator

# ── Step 1: Download & classify the GEO dataset ──────────────────────────
# USER: change "GSE158937" to your GEO ID
# USER: change cancer_type to match your cancer (see table above)
# USER: min_genes and max_mt are QC filters — adjust or remove if unsure
annotator = SampleAnnotator(
    "GSE158937",
    cancer_type="ovary_cancer",
    min_genes=200,    # cells with fewer than 200 genes are removed
    max_mt=40,        # cells with >40% mitochondrial reads are removed
)
normal, tumor, unspecified, annotation_info, query_h5ad, cancer_type, results = annotator.run()

# After run() completes, SCART prints the recommended Tabula Sapiens
# reference filename for your cancer type. Download that file if you
# haven't already, then continue with Module 2 below.
print(f"Tumour samples found: {tumor}")
print(f"Output file: {query_h5ad}")
Variant B — Multiple GEO datasets merged

To combine data from several GEO datasets into one analysis, list all IDs as separate arguments. SCART merges them and saves a single combined_tumor.h5ad. This example uses two lung cancer datasets.

python
from SCART.geo_fetcher import SampleAnnotator

# USER: add or remove GEO IDs as needed — all must be the same cancer type
annotator = SampleAnnotator(
    "GSE184880",
    "GSE173682",
    cancer_type="lung_cancer",
    min_genes=200,
    max_mt=40,
)
normal, tumor, unspecified, annotation_info, query_h5ad, cancer_type, results = annotator.run()

# Output: combined_tumor.h5ad (both datasets merged)
print(f"Output file: {query_h5ad}")
Variant C — Excluding specific samples (GSM IDs)

Some GEO datasets contain samples you do not want — for example, a CAR-T therapy study may include engineered CAR-T cell products alongside patient tumour samples. You can exclude any samples by their GSM ID. Tip: run without exclude_gsm_ids first to see the full sample list printed by SCART, then re-run with the IDs you want to drop.

python
from SCART.geo_fetcher import SampleAnnotator

annotator = SampleAnnotator(
    "GSE224550",
    cancer_type="blood_cancer",
    min_genes=200,
    max_mt=40,
    # USER: list the GSM IDs you want to exclude
    # Common use case: drop CAR-T cell product samples, keep patient PBMCs
    exclude_gsm_ids=[
        "GSM7025839", "GSM7025840",  # CAR-T product — patient P1
        "GSM7025847", "GSM7025848",  # CAR-T product — patient P2
    ],
)
normal, tumor, unspecified, annotation_info, query_h5ad, cancer_type, results = annotator.run()

After completing Module 1 for any of the variants above, continue directly to Module 2 — Cell-Type Annotation.
②

Scenario 2 — Using Your Own h5ad File(s)

If you already have processed scRNA-seq data as a .h5ad file, you can supply it directly. The file must contain raw integer counts. Also covered: supplying your own cell-type labels to skip the PopV annotation step.

What you need before starting

  • Your .h5ad file(s) with raw (un-normalised) counts in adata.X or adata.layers['counts'].
  • The Tabula Sapiens reference file for your cancer type.
  • The HPA reference file HPA_updated.h5ad.
  • (Optional) If you already have cell-type labels in your h5ad, the name of the column in adata.obs that holds them.
Variant A — Single h5ad file
python
from SCART.geo_fetcher import SampleAnnotator

# USER: replace the path with the location of your h5ad file
annotator = SampleAnnotator(
    "/path/to/my_data.h5ad",
    cancer_type="ovary_cancer",
    min_genes=200,
    max_mt=40,
)
normal, tumor, unspecified, annotation_info, query_h5ad, cancer_type, results = annotator.run()

# Output: input_tumor.h5ad
Variant B — Multiple h5ad files merged
python
from SCART.geo_fetcher import SampleAnnotator

# USER: list all h5ad files — they must all be the same cancer type
annotator = SampleAnnotator(
    "/path/to/dataset1.h5ad",
    "/path/to/dataset2.h5ad",

    max_mt=40,
)

Variant C — h5ad with your own cell-type labels (skip PopV)

If your h5ad file already contains reliable cell-type annotations (from Seurat, CellTypist, or any other tool), you can skip Module 2 (PopV) entirely by providing the column name. Important: epithelial cell labels in your column must contain the text "epithelial cell" (case-insensitive) for Module 3 to detect them correctly. Examples of valid labels: epithelial cell, glandular epithelial cell, ovarian surface epithelial cell.

python
from SCART.geo_fetcher import SampleAnnotator

annotator = SampleAnnotator(
    "/path/to/my_annotated_data.h5ad",
    cancer_type="ovary_cancer",
    min_genes=200,
    max_mt=40,
    # USER: replace "cell_type" with the actual column name in your adata.obs
    manual_annotation_col="cell_type",
)
normal, tumor, unspecified, annotation_info, query_h5ad, cancer_type, results = annotator.run()

# ✅ Skip Module 2 entirely — go straight to Module 3
⚠️
When using manual_annotation_col, your epithelial cell labels must contain the exact phrase "epithelial cell". Labels like "Epithelial" or "epithelial_cells" will not be recognised. SCART prints a warning if no epithelial cells are detected.
③

Scenario 3 — GEO ID + h5ad File Combined

You can mix GEO accession IDs and local h5ad files in the same run. SCART downloads the GEO data, loads the h5ad, and merges everything into one combined output.

python
from SCART.geo_fetcher import SampleAnnotator

# Mix GEO IDs and h5ad paths freely — all must be the same cancer type
annotator = SampleAnnotator(
    "GSE158937",                     # downloaded from GEO
    "/path/to/extra_data.h5ad",      # your own local file
    cancer_type="ovary_cancer",
    min_genes=200,
    max_mt=40,
)
normal, tumor, unspecified, annotation_info, query_h5ad, cancer_type, results = annotator.run()

# Output: combined_tumor.h5ad

Pipeline Steps — Overview

Regardless of which input scenario you used, all five modules run in the same order. Each module automatically detects the output of the previous one — you do not need to manually pass file paths between steps (unless you want to use custom locations).

StepWhat it doesOutput fileTypical time
Module 1Downloads / loads data, classifies tumour vs normal samples, applies QC*_tumor.h5ad5–30 min
Module 2Annotates cell types using PopV consensus frameworkfinal_popv_annotated.h5ad30–120 min
Module 3Identifies malignant epithelial cells (SCEVAN + scMalignantFinder), runs surfaceome differential expressionfinal_tumor.h5ad30–180 min
Module 4aScores every candidate surface gene for efficacy and safetysingle_gene_results.csv5–15 min
Module 4bFinds optimal two-gene pairs using a genetic algorithm with AND / OR / NAND logic gatestwo_gene_hof.csv30–240 min
2
Module 2 — Cell-Type Annotation (PopV)
Skip this step if you used manual_annotation_col in Module 1

PopV runs multiple annotation methods in parallel (CELLTYPIST, KNN-SCVI, SCANVI, and others) and reports a majority-vote cell-type prediction for each cell. Module 1 prints the name of the Tabula Sapiens reference file recommended for your cancer type — download that file before running this step.

ParameterStatusDefaultWhat to change
nsamplesoptional300Cells sampled per label from reference. Increase for better accuracy, decrease to save memory.
user_referencerequired—Path to the Tabula Sapiens tissue reference file for your cancer type. Download from Figshare — see the cancer type table above for the exact filename.
output_diroptional"popv_results"Where to save the annotated h5ad. Change if you want a custom location.
python
from SCART import popv_annotation

# Recommended: supply the Tabula Sapiens reference file you downloaded
# USER: replace the path with the actual location of your reference file
adata = popv_annotation.auto_run_popv(
    nsamples       = 300,
    user_reference = "/path/to/Ovary_TSP1_30_version2d_10X_smartseq_scvi_Nov262024.h5ad",
)

# Inspect the annotation results
print(adata.obs["popv_majority_vote_prediction"].value_counts())

# Output saved automatically to: popv_results/final_popv_annotated.h5ad
3
Module 3 — Malignant Cell Identification & Surfaceome DE
Requires the same Tabula Sapiens reference used in Module 2

Module 3 identifies high-confidence malignant epithelial cells using two independent tools (scMalignantFinder and SCEVAN) and then performs differential expression analysis restricted to surface-expressed genes. The "intersection" strategy — requiring both tools to agree — is strongly recommended for maximum specificity.

ParameterStatusDefaultWhat to change
reference_h5adrequired—Path to the same Tabula Sapiens file used in Module 2.
malignant_strategyoptional"intersection"Use "intersection" (both tools agree — most specific), "scMalignant" (no SCEVAN), or "scevan" (SCEVAN only).
log2fc_thresholdoptional2.0Minimum log2 fold-change for a gene to be called differentially expressed. Lower = more genes reported.
pval_adj_thresholdoptional0.05Maximum adjusted p-value. Lower = stricter statistical cutoff.
scevan_ref_max_cellsoptional100Max normal reference cells given to SCEVAN. Increase (up to 500) for a more stable baseline; decrease to save memory.
scevan_par_coresoptional1CPU cores for SCEVAN. Set to the number of cores available on your machine to speed things up.
scevan_batch_sizeoptional3000Cells processed per SCEVAN batch. Lower if you run out of memory.
scevan_organismoptional"human"Set to "mouse" for mouse data.
python
from SCART import preprocessing

# USER: replace the reference path with your Tabula Sapiens file
adata_preprocessed = preprocessing.run_preprocessing_pipeline(
    reference_h5ad     = "/path/to/Ovary_TSP1_30_version2d_10X_smartseq_scvi_Nov262024.h5ad",
    log2fc_threshold   = 2.0,
    pval_adj_threshold = 0.05,
    malignant_strategy = "intersection",
    scevan_ref_max_cells = 100,
    scevan_sample_name   = "SCEVAN_run",
    scevan_organism      = "human",
    scevan_par_cores     = 1,
    scevan_subclones     = False,
    scevan_batch_size    = 3000,
)

# Inspect top differentially expressed surface genes
print(adata_preprocessed.uns["filtered_deg"].head(20))

# Output saved to: preprocessing_results/final_tumor.h5ad
4a
Module 4a — Single-Gene CAR-T Target Scoring
Requires HPA_updated.h5ad downloaded from GitHub

Module 4a scores every surface gene identified in Module 3 for two properties: Efficacy (how well the gene distinguishes tumour cells) and Safety (how absent the gene is from healthy tissues according to the Human Protein Atlas). Higher is better for both.

ParameterStatusDefaultWhat to change
hpa_pathrequired—Path to HPA_updated.h5ad. If omitted, SCART attempts an auto-download.
safety_thresholdoptional0.9Fraction of healthy cell types that must NOT express the target. 0.9 = 90% safety (recommended). Lower to get more candidates, raise for stricter safety.
python
from SCART.gene_combination_predictor import one_gene_combination

# USER: replace the path with the location of your HPA_updated.h5ad
df = one_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
)

# Filter and inspect top candidates
top = df[df["Safety"] >= 0.9].sort_values("Efficacy", ascending=False)
print(top.head(20))

# Output saved to: single_gene_results.csv
4b
Module 4b — Two-Gene Logic-Gate Scoring
Searches for optimal gene pairs using a genetic algorithm

Module 4b extends the single-gene analysis to pairs of genes, evaluated with three logic gates: A & B (both expressed), A | B (either expressed), and A &! B (A expressed, B not expressed — NAND gate for safety). A genetic algorithm efficiently searches the combination space.

ParameterStatusDefaultWhat to change
hpa_pathrequired—Path to HPA_updated.h5ad.
safety_thresholdoptional0.9Same as Module 4a.
pop_sizeoptional1000Number of gene pairs evaluated per generation. Larger = more thorough search but slower.
Gmaxoptional100Maximum number of generations the algorithm runs.
patienceoptional50Early stop if no improvement for N generations.
n_cpusoptional1CPU cores for parallel evaluation. Set to the number of cores available to you.
n_runsoptional10Independent GA runs with different random seeds. More runs = more robust results.
python
from SCART.gene_combination_predictor import two_gene_combination

# USER: replace the path with the location of your HPA_updated.h5ad
# USER: set n_cpus to the number of CPU cores on your machine
df_hof, df_all = two_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
    pop_size         = 1000,
    Gmax             = 100,
    patience         = 50,
    n_cpus           = 8,
    n_runs           = 10,
)

# View best AND-gate combinations
and_pairs = df_hof[df_hof["LogicGates"] == "A & B"]
print(and_pairs.head(10))

# View best NAND-gate combinations (A expressed, B absent — safer targeting)
nand_pairs = df_hof[df_hof["LogicGates"] == "A &! B"]
print(nand_pairs.head(10))

# Outputs: two_gene_hof.csv (best pairs) and two_gene_complete.csv (all evaluated pairs)

Step 1 — Choose your input (pick one of three scenarios)

The only thing that changes between scenarios is how you construct the SampleAnnotator call. Everything from Module 2 onwards is identical regardless of which scenario you use.

python — Module 1 · Data Input
import SCART
from SCART.geo_fetcher import SampleAnnotator

# ════════════════════════════════════════════════════════════════════════════
#  SCENARIO ① — One GEO accession ID
#  Use this when your data comes from a public GEO dataset.
#  SCART downloads and processes everything automatically.
# ════════════════════════════════════════════════════════════════════════════

annotator = SampleAnnotator(
    "GSE158937",          # ← CHANGE: your GEO accession ID (format: GSExxxxxx)
                           #   Find IDs at: ncbi.nlm.nih.gov/geo

    cancer_type="ovary_cancer",  # ← CHANGE: use a key from the Cancer Type table above
                                   #   This tells SCART which Tabula Sapiens reference
                                   #   file to recommend after the run

    min_genes=200,         # ← OPTIONAL quality filter: cells with fewer than this
                           #   many detected genes are removed before analysis.
                           #   Typical range: 100–500. Remove this line entirely
                           #   to skip the filter (not recommended).

    max_mt=40,             # ← OPTIONAL quality filter: cells where more than this
                           #   percentage of reads come from mitochondrial genes are

python — Module 3 · Malignant Cell Identification
from SCART import preprocessing

adata_preprocessed = preprocessing.run_preprocessing_pipeline(

    reference_h5ad="/path/to/Ovary_TSP1_30_version2d_10X_smartseq_scvi_Nov262024.h5ad",
                           # ← CHANGE: same Tabula Sapiens file used in Module 2.
                           #   This is used to build a healthy reference for SCEVAN,
                           #   which detects copy number variations to identify
                           #   malignant cells.

    malignant_strategy="intersection",
                           # ← RECOMMENDED: "intersection" means BOTH scMalignantFinder
                           #   AND SCEVAN must agree that a cell is malignant.
                           #   This gives the highest confidence results — fewer false
                           #   positives, better CAR-T targets downstream.
                           #
                           #   Alternatives (use only if you have a specific reason):
                           #   "scMalignant" — use scMalignantFinder only (no SCEVAN).
                           #     Use if you do not have a Tabula Sapiens reference or
                           #     want a faster run. Less specific than intersection.
                           #   "scevan"       — use SCEVAN only.

    log2fc_threshold=2.0,  # ← Minimum fold-change a gene must show between malignant
                           #   and non-malignant cells to be called differentially
                           #   expressed (and thus a candidate CAR-T target).
                           #   log2FC of 2.0 means the gene is expressed ~4× higher
                           #   in tumour cells — a stringent, sensible default.
                           #   Increase (e.g. 3.0) for a shorter, higher-confidence
                           #   target list. Decrease (e.g. 0.5–1.0) if you are getting
                           #   very few candidates and want to cast a wider net.

    pval_adj_threshold=0.05,
                           # ← Maximum adjusted p-value for a gene to be included.
                           #   0.05 is the standard statistical significance cutoff
                           #   (5% false discovery rate). Only change this if you
                           #   have a specific statistical reason — 0.05 is almost
                           #   always appropriate.

    scevan_ref_max_cells=100,
                           # ← Maximum number of healthy reference cells given to
                           #   SCEVAN per run. 100 is a conservative, memory-safe
                           #   default that works on most machines.
                           #   Increase to 200–500 if you have 32+ GB RAM — a larger
                           #   reference gives SCEVAN a more stable baseline, which
                           #   can improve malignant cell detection accuracy.
                           #   Decrease if SCART runs out of memory.

    scevan_par_cores=1,    # ← CPU cores used by SCEVAN. Set this to the number of
                           #   cores available on your machine to speed things up.
                           #   On a standard laptop: 4. On a workstation: 8–16.
                           #   On HPC: match to --cpus-per-task in your SLURM script.

    scevan_batch_size=3000,
                           # ← How many tumour cells are processed per SCEVAN batch.
                           #   3000 works for most machines with ≥16 GB RAM.
                           #   Decrease (e.g. 1000–1500) if you run out of memory.
                           #   Increase (e.g. 5000) if you have 64+ GB RAM and want
                           #   fewer, faster batches.

    scevan_organism="human",
                           # ← Set to "mouse" if your data is from mouse samples.
                           #   Leave as "human" for all human cancer data.

    scevan_sample_name="SCEVAN_run",
                           # ← A label used as a prefix for SCEVAN's output files.
                           #   You can change this to anything descriptive, e.g.
                           #   "GSE158937_ovary". It does not affect results.

    scevan_subclones=False,
                           # ← Whether SCEVAN should try to detect tumour subclones
                           #   (genetically distinct sub-populations within the tumour).
                           #   False is faster and sufficient for CAR-T target discovery.

)

Step 4b — Two-gene logic-gate CAR-T target scoring

This module searches for optimal pairs of genes, tested with three logic gates: A & B (target cells expressing both genes), A | B (expressing either), and A &! B (expressing A but not B — useful for safety, since a healthy-tissue marker can be used as an exclusion signal). A genetic algorithm efficiently explores millions of possible pairs.

python — Module 4b · Two-Gene Combination Scoring
from SCART.gene_combination_predictor import two_gene_combination

df_hof, df_all = two_gene_combination.run(

    hpa_path="/path/to/HPA_updated.h5ad",
                           # ← CHANGE: same HPA file as Module 4a.

    safety_threshold=0.9, # ← Same meaning as Module 4a. 0.9 is recommended.

    pop_size=1000,         # ← Number of gene pairs in each "generation" of the
                           #   genetic algorithm. Think of it as the population size
                           #   in an evolutionary search — larger means the algorithm
                           #   explores more of the search space per generation.
                           #   200  → fast test run (laptop / first look)
                           #   1000 → standard run (recommended)
                           #   2000 → thorough run (HPC, large gene lists)

    Gmax=100,              # ← Maximum number of generations the algorithm is allowed
                           #   to run. More generations = more optimisation time.
                           #   In practice the algorithm often stops early (see patience).
                           #   20  → quick test
                           #   100 → standard (recommended)
                           #   200 → thorough (HPC)

    patience=50,           # ← Early stopping: if the best score has not improved for
                           #   this many consecutive generations, the algorithm stops.
                           #   This saves time when results have converged.
                           #   10  → stops quickly, may miss small improvements
                           #   50  → standard balance (recommended)
                           #   100 → keeps running longer, for thorough HPC runs

    n_cpus=8,              # ← CPU cores for parallel fitness evaluation. This is the
                           #   single biggest speed lever for Module 4b.
                           #   Set to the number of cores your machine has:
                           #   4  → laptop
                           #   8  → standard workstation (recommended)
                           #   16–40 → HPC node

    n_runs=10,             # ← Number of independent algorithm runs with different
                           #   random starting points. Because genetic algorithms have
                           #   a random component, running multiple times and combining
                           #   results gives more robust and reproducible output.
                           #   2   → quick test only
                           #   10  → standard, reliable (recommended)
                           #   10+ → diminishing returns beyond 10 for most datasets
)

# View the best AND-gate pairs (both genes must be expressed on tumour cell)
and_pairs = df_hof[df_hof["LogicGates"] == "A & B"]
print("Top AND-gate pairs:"); print(and_pairs.head(10))

# View the best NAND-gate pairs (tumour expresses A but NOT B —
# B acts as a "safety catch" to spare healthy cells that express B)
nand_pairs = df_hof[df_hof["LogicGates"] == "A &! B"]
print("Top NAND-gate pairs:"); print(nand_pairs.head(10))
