Tutorial Overview

This tutorial uses a lung cancer GEO dataset (GSE131907) as an example. Follow each module in order. All intermediate outputs are saved automatically and auto-detected by downstream modules.

ℹ️
Make sure your scart_env conda environment is active before starting. See the Installation guide if you haven't set it up yet.

Module 1 — GEO Data Acquisition

Download scRNA-seq data from GEO, classify samples as tumour/normal, apply QC filters, and write a tumour h5ad file.

python
from SCART.geo_fetcher import SampleAnnotator

# Single GEO dataset with QC thresholds
annotator = SampleAnnotator(
    "GSE131907",
    cancer_type="lung_cancer",
    min_genes=200,
    max_mt=40
)

normal, tumor, unspecified, annotation_info, \
    query_h5ad, cancer_type, results = annotator.run()

print(f"Tumour samples: {tumor}")
print(f"Output: {query_h5ad}")

Common variants

python
# Multiple GEO IDs merged into combined_tumor.h5ad
annotator = SampleAnnotator(
    "GSE131907", "GSE150430",
    cancer_type="lung_cancer",
    min_genes=200, max_mt=40
)

# Exclude specific GSM IDs (e.g. CAR-T products)
annotator = SampleAnnotator(
    "GSE224550",
    cancer_type="blood_cancer",
    exclude_gsm_ids=["GSM7025839", "GSM7025840"]
)

# User-supplied h5ad with existing annotations → skip Module 2
annotator = SampleAnnotator(
    "my_data.h5ad",
    cancer_type="ovary_cancer",
    manual_annotation_col="cell_type"
)

Module 2 — Cell-Type Annotation (PopV)

Annotate cell types using the PopV consensus framework with a Tabula Sapiens tissue reference. Module 1 prints the recommended reference file name for your cancer type at the end of its run.

ℹ️
Skip this module if you used manual_annotation_col in Module 1. Proceed directly to Module 3.
python
from SCART import popv_annotation

# Option A: Provide downloaded Tabula Sapiens reference (recommended)
# Module 1 printed: "Download Lung_TSP1_30_version2d_10X_smartseq_scvi.h5ad"
adata = popv_annotation.auto_run_popv(
    input_type     = "raw",
    nsamples       = 300,
    user_reference = "/path/to/Lung_TSP1_30_version2d_10X_smartseq_scvi.h5ad"
)

# Option B: Auto-download reference (requires internet)
adata = popv_annotation.auto_run_popv(
    input_type = "raw",
    nsamples   = 300
)

print(adata.obs["popv_majority_vote_prediction"].value_counts())

Output is saved to popv_results/final_popv_annotated.h5ad and auto-detected by Module 3.

Module 3 — Malignant Cell Identification

Identify high-confidence malignant epithelial cells and perform surfaceome differential expression. The "intersection" strategy (both scMalignantFinder and SCEVAN must agree) is recommended for maximum specificity.

python
from SCART import preprocessing

# Standard run with both tools (recommended)
adata_preprocessed = preprocessing.run_preprocessing_pipeline(
    reference_h5ad     = "/path/to/Lung_TSP1_30_version2d_10X_smartseq_scvi.h5ad",
    log2fc_threshold   = 2.0,
    pval_adj_threshold = 0.05,
    malignant_strategy = "intersection",
)

# Inspect top differentially expressed surface genes
deg = adata_preprocessed.uns["filtered_deg"]
print(deg.head(20))

If scMalignantFinder only (no SCEVAN / no reference)

python
adata_preprocessed = preprocessing.run_preprocessing_pipeline(
    malignant_strategy = "scMalignant",
    log2fc_threshold   = 2.0,
    pval_adj_threshold = 0.05,
)

Module 4a — Single-Gene Scoring

Score every surfaceome-DE candidate gene for tumour efficacy and healthy-tissue safety.

python
from SCART.gene_combination_predictor import one_gene_combination

df = one_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
)

# Filter and sort by efficacy
top = df[df["Safety"] >= 0.9].sort_values("Efficacy", ascending=False)
print(top.head(20))
top.to_csv("top_single_gene_targets.csv", index=False)

Module 4b — Two-Gene Logic-Gate Scoring

Search for optimal two-gene combinations using a genetic algorithm. Each gene pair is evaluated with AND, OR, and NAND logic gates.

python
from SCART.gene_combination_predictor import two_gene_combination

df_hof, df_all = two_gene_combination.run(
    hpa_path         = "/path/to/HPA_updated.h5ad",
    safety_threshold = 0.9,
    pop_size         = 1000,
    Gmax             = 100,
    patience         = 50,
    n_cpus           = 8,
    n_runs           = 10,
)

# Best AND-gate combinations
and_pairs = df_hof[df_hof["LogicGates"] == "A & B"]
print(and_pairs.head(10))

# Best NAND-gate combinations
nand_pairs = df_hof[df_hof["LogicGates"] == "A &! B"]
print(nand_pairs.head(10))

SBATCH Guide — Running on HPC Clusters

For large datasets, SCART is best run on an HPC cluster using SLURM job arrays or sequential job submissions. Each module is computationally independent and can be submitted as a separate SBATCH job.

💡
Modules 3 and 4b are the most memory- and CPU-intensive. Allocate at least 32 GB RAM and 8+ cores for Module 4b with standard settings (pop_size=1000, n_cpus=8).

Full SBATCH Script — All Modules

This script runs the complete SCART pipeline end-to-end as a single SLURM job. Adjust the resource directives, paths, and parameters for your cluster and dataset.

#SBATCH --mem=64G
#SBATCH --time=12:00:00

Submitting and Monitoring Jobs

Save the script above as scart_pipeline.sh, edit the variables at the top, then submit:

bash
# Make the script executable
chmod +x scart_pipeline.sh

# Create the logs directory
mkdir -p logs

# Submit the job
sbatch scart_pipeline.sh

# Monitor status
squeue -u $USER

# View live output
tail -f logs/scart_*.out

Running modules as separate jobs (recommended for large datasets)

For very large datasets, submit each module as a separate job with dependencies so they run in sequence automatically:

bash
# Submit module 1 and capture job ID
JOB1=$(sbatch --parsable scart_module1.sh)
echo "Module 1 job: $JOB1"

# Submit module 2 — only runs after module 1 succeeds
JOB2=$(sbatch --parsable --dependency=afterok:$JOB1 scart_module2.sh)
echo "Module 2 job: $JOB2"

# Submit module 3 — only runs after module 2 succeeds
JOB3=$(sbatch --parsable --dependency=afterok:$JOB2 scart_module3.sh)
echo "Module 3 job: $JOB3"

# Submit modules 4a and 4b in parallel (both depend on module 3)
sbatch --dependency=afterok:$JOB3 scart_module4a.sh
sbatch --dependency=afterok:$JOB3 scart_module4b.sh
💡
Split the single SBATCH script into individual module scripts by extracting each python - <<EOF … EOF block into its own scart_moduleN.sh file with appropriate #SBATCH resource directives per the table above.
